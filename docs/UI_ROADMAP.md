# UI Roadmap — MarketMind AI

Дата: 2026-07-14
Статус: Анализ + план

## Текущее состояние интерфейса

### Существующие страницы

| Страница | URL | Статус |
|---|---|---|
| Панель управления | `/` | ✅ Работает |
| Товары | `/products` | ✅ Работает |
| Карточка товара | `/products/{id}` | ✅ Работает |
| Импорт | `/import` | ✅ Работает |
| AI Предложения | `/suggestions` | ✅ Работает |

### Что делает специалист сегодня

1. Открывает Dashboard → видит статистику
2. Загружает CSV/Excel → товары обрабатываются
3. Просматривает товары → фильтрует и ищет
4. Открывает карточку товара → видит данные, анализ, AI-предложения
5. Принимает/отклоняет AI-предложения

### Чего не хватает для работы с клиентом

| Проблема | Влияние |
|---|---|
| Нет отчётов для клиента | Специалист не может показать результат работы |
| Нет анализа магазина | Невозможно оценить состояние каталога в целом |
| Нет настроек в UI | Невозможно настроить без CLI |
| Нет экспорта из UI | Невозможно скачать результат |
| Нет истории изменений клиента | Невозможно отследить прогресс |

## Дорожная карта интерфейса

### 1. Главный экран (Dashboard)

**Цель:** Обзор системы для специалиста.

**Что должен видеть пользователь:**
- Количество товаров в системе
- Средний Quality Score
- Количество критических проблем
- Последние AI-предложения
- Быстрые действия (Импорт, Товары, Отчёт)

**Приоритет:** Высокий (уже реализован)

### 2. Страница товаров

**Цель:** Просмотр и управление каталогом товаров.

**Что должен видеть пользователь:**
- Таблица товаров с поиском
- Фильтры: маркетплейс, наличие, Quality Score
- Быстрый переход к карточке товара
- Массовые действия (выбрать все → Apply AI)

**Приоритет:** Высокий (уже реализован)

### 3. Карточка товара

**Цель:** Детальная информация о конкретном товаре.

**Что должен видеть пользователь:**
- Основные данные (название, фото, цена, бренд)
- Оценка качества (0-100)
- Найденные проблемы
- AI-предложения с approve/reject
- История изменений
- График цен

**Приоритет:** Высокий (уже реализован)

### 4. Анализ магазина

**Цель:** Оценка состояния каталога в целом.

**Что должен видеть пользователь:**
- Общая статистика: товаров, средний Score, критические проблемы
- Распределение товаров по Quality Score
- Топ проблемы (частые finding-и)
- Товары, требующие внимания
- Сравнение маркетплейсов

**Приоритет:** Высокий (✅ реализован в P3.5)

### 5. Отчёты клиента

**Цель:** Формирование отчёта для клиента.

**Что должен видеть пользователь:**
- Что было сделано
- Какие проблемы найдены
- Какие исправления предложены
- Текущее состояние каталога
- Рекомендации по улучшению

**Приоритет:** Средний (коммерческая ценность)

### 6. Настройки

**Цель:** Конфигурация системы через UI.

**Что должен видеть пользователь:**
- Выбор AI-провайдера
- API-ключи (с маскировкой)
- Пороговые значения Quality Score
- Настройки парсинга
- Экспорт/импорт конфигурации

**Приоритет:** Низкий (можно через CLI)

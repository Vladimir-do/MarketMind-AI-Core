# P3.4 Report — Product Detail (Карточка товара)

Дата: 2026-07-14
Проект: `MarketMind-AI-Core-main`

## Цель P3.4

Создать центральную страницу товара — главное рабочее место специалиста по маркетплейсам.

## Структура страницы

```
/products/{id}
├── Карточка товара
│   ├── Название, фото, цена
│   ├── Бренд, категория
│   └── Характеристики
├── Оценка качества карточки (0-100)
├── Найденные проблемы (20 правил)
├── Предложения программы (AI)
│   ├── Было → Новое
│   ├── Причина
│   └── Принять / Отклонить / Вернуть назад
├── История изменений
└── История цены (график Chart.js)
```

## API Endpoints

| Метод | Путь | Описание |
|---|---|---|
| GET | `/products/{id}` | Страница товара (HTML) |
| GET | `/api/products/{id}` | Данные товара (JSON) |
| GET | `/api/products/{id}/prices` | История цен (JSON) |
| GET | `/api/products/{id}/analysis` | Результат анализа (JSON) |
| GET | `/api/products/{id}/suggestions` | AI предложения (JSON) |
| GET | `/api/products/{id}/history` | История одобрений (JSON) |

## Блоки страницы

### Карточка товара
- Название (заголовок)
- Фото (или "Нет фото")
- Цена + старая цена + скидка
- Бренд, категория
- Характеристики из attributes

### Оценка качества карточки
- SVG-диаграмма с цветовым индикатором
- Уровни: Отлично (90+), Хорошо (75+), Удовлетворительно (50+), Плохо (25+), Критично (<25)

### Найденные проблемы
- Таблица: поле, сообщение, категория, серьёзность
- Цвета: Критично=красный, Внимание=жёлтый, Инфо=серый

### Предложения программы
- Было → Новое (сравнение)
- Причина изменения
- Уверенность (процент)
- Кнопки: Принять / Отклонить

### История изменений
- Временная шкала одобрений
- Статус: Принято / Отклонено / Откачено

### История цены
- График через Chart.js
- Ось X: дата, Ось Y: цена (₽)

# Real Order Checklist

Простая инструкция для первого реального заказа в MarketMind AI.

## 1. Запустить программу

Linux:

```bash
cd /mnt/steam/Proekt/MarketMind-AI-Core-main
./start_marketmind.sh
```

Windows:

```bat
cd путь\к\MarketMind-AI-Core-main
start_marketmind.bat
```

Откройте:

```text
http://127.0.0.1:18080/projects
```

На странице должен быть зелёный banner:

```text
РАБОЧИЙ РЕЖИМ. ДАННЫЕ СОХРАНЯЮТСЯ
```

## 2. Создать проект заказчика

1. Откройте `Проекты`.
2. Нажмите `Новый проект`.
3. Заполните название проекта, заказчика и маркетплейс.
4. Откройте созданный проект.

## 3. Загрузить файл

1. В проекте нажмите `Импорт`.
2. Выберите CSV/XLSX файл заказчика.
3. Проверьте preview, кодировку, колонки и mapping.
4. Сохраните preset mapping, если такие файлы будут повторяться.
5. Подтвердите импорт только после проверки preview.

## 4. Сделать backup

1. Откройте `Состояние системы`.
2. Нажмите `Создать резервную копию`.
3. Убедитесь, что backup появился в списке с датой, размером и checksum.

## 5. Обработать товары

1. Откройте `Товары` внутри проекта.
2. Проверьте карточки.
3. При необходимости откройте карточку товара и используйте ручной редактор.
4. Перед применением правки проверьте diff.
5. При ошибке используйте версию/rollback с понятной причиной.

## 6. Экспортировать результат

1. Откройте `Экспорт`.
2. Создайте CSV, JSON или XLSX.
3. Скачайте созданный файл.
4. Откройте `Отчёты`.
5. Создайте HTML, JSON или CSV отчёт.
6. Скачайте отчёт.

## 7. Архивировать заказ

1. Откройте карточку проекта.
2. Нажмите `Скачать полный архив проекта`.
3. Сохраните zip-файл заказчику или во внутренний архив.
4. Если заказ завершён, нажмите `Архивировать проект`.

Архивирование не удаляет файлы.

## 8. Безопасно остановить программу

Вернитесь в терминал, где запущен `start_marketmind.sh` или `start_marketmind.bat`, и нажмите:

```text
Ctrl+C
```

После повторного запуска через `./start_marketmind.sh` проекты и файлы должны остаться на месте.

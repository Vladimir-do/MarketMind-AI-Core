# Stage 1 Report — Project Stabilization

Дата: 2026-07-14  
Проект: `MarketMind-AI-Core-main`

## Что было сломано

- Старое виртуальное окружение `.venv` было непригодно для запуска:
  - отсутствовал `pip`;
  - `pytest` не был установлен;
  - зависимостей не хватало для воспроизводимого запуска.
- В исходной конфигурации зависимостей был конфликт:
  - `aiogram 3.4.1` требовал `aiohttp~=3.9.0`;
  - в `requirements.txt` был зафиксирован `aiohttp==3.11.14`.
- `Database.init()` ранее зависал в старой среде при работе через async SQLite / SQLAlchemy.
- В Telegram startup была неустойчивая proxy-fallback логика: при падении прокси session создавалась повторно, что ломало тестовый контракт и усложняло стабильный запуск.

## Настоящая причина

Главная воспроизводимая проблема на этом этапе оказалась окруженческой:

- сломанный `.venv`;
- конфликт пинов в `requirements.txt`;
- нестабильное поведение старой среды при async SQLite.

В новом чистом `.venv`:

- `aiosqlite.connect(':memory:')` проходит с таймаутом;
- `Database.init()` успешно создаёт таблицы во временной БД;
- полный тестовый набор проходит.

## Что изменено

- `.gitignore`
  - добавлены/зафиксированы явные правила для runtime-артефактов и generated output.
- `requirements.txt`
  - `aiohttp==3.11.14` заменён на `aiohttp==3.9.5` для совместимости с `aiogram 3.4.1`.
- `app/telegram_runtime.py`
  - proxy fallback теперь переиспользует один session-объект и не создаёт лишнюю сессию при падении прокси.
- `docs/PROJECT_AUDIT.md`
  - добавлен блок с фактическими результатами Stage 1.
- `docs/DEVELOPMENT_PLAN.md`
  - добавлен фактический статус первого этапа.

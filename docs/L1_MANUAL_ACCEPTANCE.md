# L1.1 Manual Acceptance

Статус: `AWAITING_OWNER_ACCEPTANCE`

Эта проверка должна быть выполнена владельцем проекта в реальном браузере. Codex подготовил demo-среду и проверил routes тестами, но не должен объявлять ручную приёмку завершённой без владельца.

## 1. Подготовить demo

Linux:

```bash
cd /mnt/steam/Proekt/MarketMind-AI-Core-main
./start_l1_demo.sh
```

Windows:

```bat
cd путь\к\MarketMind-AI-Core-main
start_l1_demo.bat
```

Запускатор создаст временную БД и покажет:

- идентификатор demo-проекта;
- путь к файлу `l1_demo_products.csv`;
- адрес интерфейса.

## 2. Открыть программу

Адрес по умолчанию:

```text
http://127.0.0.1:18080/projects
```

## 3. Проверить сценарий

1. Откройте список проектов.
2. Откройте demo-проект «Демонстрационный заказ L1.1».
3. Нажмите импорт файла.
4. Выберите demo-файл `l1_demo_products.csv`, путь показан скриптом.
5. Убедитесь, что открывается preview, а товары ещё не сохранены.
6. Проверьте кодировку, разделитель, число строк, первые строки и mapping колонок.
7. Сохраните сопоставление под понятным названием.
8. Скачайте CSV отчёта ошибок.
9. Подтвердите импорт.
10. Откройте список товаров проекта.
11. Откройте карточку товара.
12. Откройте ручной редактор и измените название или описание.
13. Проверьте diff перед применением.
14. Примените правку.
15. Откройте версии и выполните rollback с причиной.
16. Создайте CSV, JSON и XLSX экспорт.
17. Скачайте экспортные файлы.
18. Создайте HTML, JSON и CSV отчёт.
19. Скачайте отчёт.
20. Перезапустите программу той же командой и убедитесь, что проект сохранился.

## 4. Ожидаемый результат

- Основной путь идёт через preview и mapping.
- Preset сопоставления можно выбрать при повторном preview такого же файла.
- Ошибки видны на русском языке.
- CSV отчёта ошибок скачивается.
- Корректные строки импортируются, ошибочные остаются в отчёте.
- Ручная правка не меняет глобальный товар вне проекта.
- Rollback создаёт новую версию.
- Экспорт строится из Effective Card.
- Отчёт содержит итог проекта.

## 5. Как сообщить об ошибке

Запишите:

- шаг, на котором произошла ошибка;
- адрес страницы;
- текст сообщения;
- что ожидалось;
- что произошло;
- файл экспорта или отчёта, если проблема в результате.

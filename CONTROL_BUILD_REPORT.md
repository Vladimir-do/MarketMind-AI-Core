# MarketMind AI — контрольная сборка Stage 7

## Что объединено

Сборка сформирована из полного набора переданных архивов и включает исправления Stage 3–6:

- единый AI provider pipeline;
- единый runtime и путь базы данных;
- структурированная диагностика AI/Gemini;
- отображение ошибок фоновых AI-задач в веб-интерфейсе;
- восстановленные Alembic-миграции и служебные файлы репозитория;
- исправлена коллизия имён skill-note файлов, создаваемых в одну секунду;
- тест совместимости aiohttp больше не зависит от наличия или отсутствия одного класса в конкретной версии.

## Поддерживаемая версия Python

Использовать Python 3.11 или 3.12. В `pyproject.toml` установлен диапазон `>=3.11,<3.13`, поскольку стек закрепляет aiogram 3.4.1 и aiohttp 3.9.5.

## Установка

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements-dev.txt
playwright install chromium
```

## Проверка

```bash
./scripts/verify_control_build.sh
```

## Результат в среде аудита

- компиляция `app` и `tests`: успешно;
- 28 целевых AI/UI/skill-note тестов и 4 subtests: успешно;
- при неполном общем прогоне 459 тестов прошли;
- полный pytest не завершён, потому что внутренний пакетный индекс среды не предоставил `aiogram` и `aiosqlite`;
- 200 падений общего прогона были преимущественно следствием отсутствующего `aiosqlite`, а три Telegram-модуля не прошли сборку из-за отсутствующего `aiogram`;
- три интеграционных Gemini→JobRecord теста также требуют `aiosqlite` и в этой среде не выполнялись.

Это ограничение среды проверки. Полная зелёная проверка должна быть выполнена после установки `requirements-dev.txt` на Python 3.11/3.12.

## Очистка релиза

Из контрольного архива удалены:

- виртуальное окружение;
- `__pycache__`, `.pyc`, pytest/ruff cache;
- логи;
- browser profile;
- рабочие базы и содержимое runtime.

Каталоги runtime сохранены пустыми с `.gitkeep`.

## Перенос старой базы

1. Полностью остановить MarketMind.
2. Сделать резервную копию `app/data/parser.db`.
3. Скопировать базу в `runtime/database/marketmind.db`.
4. Не удалять исходную базу до проверки проектов, товаров и истории.
